These are instructions for building the NUI yourself. 
Note that this is only needed when you changed something in the NUI yourself, or if you cloned the repository source code instead of installing the release.

1. Install node.js: https://nodejs.org/en/download
2. open cmd/terminal
3. Navigate to the resources web folder, for example: cd C:\Users\loki\Downloads\loki_prescriptions\web replace the path with wherever your folder actually is
4. type "npm ci", this will install all the dependencies
5. type "npm run build" to actually build the NUI.
6. restart the resource
