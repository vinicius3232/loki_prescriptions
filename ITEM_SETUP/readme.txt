Para configurar os itens necessários para o loki_prescriptions funcionar:

1. Se você usa ox_inventory:
   Copie as definições prontas presentes no arquivo ITEM_SETUP/items_ox.lua para o seu ox_inventory/data/items.lua.
   Copie os ícones da pasta ITEM_SETUP/images/ para a pasta ox_inventory/web/images/.

2. Se você usa qb-inventory ou qs-inventory:
   Consulte os arquivos qb.txt e ox_inventory.txt para os snippets correspondentes.
